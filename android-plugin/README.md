# RokidHub · Codex Nexus plugin

Отдельный Nexus plugin id: `rokidhub.codex`. Он не использует и не меняет
credential/контракт `rokidhub.yandex`.

Скелет переносит проверенный UX существующего плагина:

- `NexusSpeechSession` для STT;
- `NexusCard` для HUD;
- `NexusTtsSession` только для короткого финального итога;
- одноразовая pairing-привязка и Android Keystore для Nexus bearer token.

Поток HUD: `Подключаю ПК` → `Codex анализирует` → `Нужен ответ` / `Готово`.
В мелком footer HUD постоянно показывается короткое имя активного проекта.
Абсолютный путь в Nexus и RokidHub не передаётся.
Команды `продолжай`, `останови`, `коротко что нашёл?` преобразуются в
`continue/steer`, `interrupt`, `summarize` с тем же `conversation_id`.

Голосовая команда `выбери проект <имя>` создаёт локальный контекст проекта.
Hub получает только произнесённое имя; абсолютный путь сопоставляет и хранит
Desktop Connector. После ответа «Выбран проект …» следующий голосовой запрос
продолжает тот же `conversation_id` уже в выбранной папке.

Debug APK собирается локально. Release signing и публикация выполняются отдельно
и не должны добавлять ключи или секреты в репозиторий.

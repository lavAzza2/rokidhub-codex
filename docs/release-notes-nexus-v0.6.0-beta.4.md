# RokidHub · Codex Nexus v0.6.0-beta.4

Публичная beta-версия Nexus-плагина для связи очков Rokid с локальным Codex через RokidHub Desktop Connector.

## Что входит

- голосовые запросы через STT;
- статусы и краткий результат в HUD;
- краткая голосовая сводка через TTS;
- выбор разрешённого проекта голосом, включая пользовательские алиасы;
- команды продолжения и остановки текущей задачи;
- съёмка фотографии по голосовой команде и передача её локальному Codex;
- отдельная отзывная привязка очков к аккаунту RokidHub.

## Что изменилось в beta.4

- APK пересобран из точного Git-тега с проверяемой информацией о commit;
- версия и метаданные подготовлены для публикации в официальном реестре Nexus;
- сохранён прежний сертификат подписи, поэтому обновление устанавливается поверх beta.3.

Для работы также нужен RokidHub Desktop Connector на Windows и привязка обоих устройств к одному аккаунту RokidHub.

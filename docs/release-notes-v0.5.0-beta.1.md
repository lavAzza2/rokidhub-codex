# RokidHub · Codex 0.5.0 beta 1

Первый публичный вертикальный срез интеграции Rokid RV101 с локальным Codex.

## Что входит

- Nexus APK с STT, HUD, коротким TTS, отдельной привязкой и RU/EN;
- Windows Desktop Connector с GUI, треем, автозагрузкой, выбором разрешённых
  папок, проекта по умолчанию, модели, reasoning effort и service tier;
- локальные режимы доступа: только чтение, запрос подтверждения и запись только
  внутри выбранного проекта;
- локальный Codex App Server: новые треды, продолжение, steer, interrupt и
  поток финального результата;
- голосовой выбор проекта и продолжение одного диалога.

## Установка

Скачай APK и EXE ниже. Сначала привяжи ПК через **Настройки** Connector, затем
привяжи Nexus-плагин в карточке Codex на [rokidhub.com](https://rokidhub.com).

Windows EXE пока не имеет коммерческой Authenticode-подписи, поэтому SmartScreen
может показать предупреждение. Сверь SHA-256 с `SHA256SUMS.txt`.

Android APK подписан постоянным релизным ключом RokidHub Codex. Обновления APK
должны использовать тот же ключ.

Это beta-версия: начни с режима «Только чтение» и явно выбери разрешённые папки.

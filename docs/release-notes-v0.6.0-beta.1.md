# RokidHub · Codex 0.6.0 beta 1

В этом beta-релизе очки Rokid RV101 могут по явной голосовой команде сделать
один снимок и передать его локальному Codex на выбранном ПК.

## Что нового

- команды «Сделай фото и опиши…» / “Take a photo and describe it”;
- отдельное разрешение Camera в Nexus и видимые состояния съёмки в HUD;
- уменьшение кадра до 2048 px, повторное JPEG-кодирование без исходного EXIF и
  лимит 5 МБ;
- одноразовая доставка фото только Connector того же пользователя и текущего
  job lease;
- проверка размера, JPEG-маркеров и SHA-256 перед передачей Codex App Server;
- штатный App Server input `localImage`, проверенный с Codex CLI 0.144.5;
- удаление фото из RokidHub после скачивания и локального временного файла после
  завершения turn;
- пользовательские голосовые псевдонимы проектов для вариантов распознавания
  вроде `RokidCodex` / `Рокет Codex`;
- более точный индикатор: зелёный статус Connector показывается только когда
  его рабочий процесс действительно запущен.

Полный путь фото проверен на production RokidHub: RV101 → Nexus → RokidHub →
Windows Connector → локальный Codex → краткий ответ в HUD.

## Установка

Обнови APK через Nexus и разреши для `RokidHub · Codex` возможность Camera.
Обнови Windows Connector тем же EXE. При установке поверх предыдущей версии с
той же подписью привязки сохраняются.

Windows EXE пока не имеет коммерческой Authenticode-подписи, поэтому SmartScreen
может показать предупреждение. Сверь SHA-256 с `SHA256SUMS.txt`.

Начинай с режима «Только чтение» и добавляй только необходимые папки проектов.
Фоновая съёмка, видео и автоматические опасные действия не поддерживаются.

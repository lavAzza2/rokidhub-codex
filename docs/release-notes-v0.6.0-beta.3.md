# RokidHub Codex v0.6.0-beta.3

This release removes a duplicated access-mode selector from RokidHub Desktop
Connector.

Overview now shows the active access policy as a compact, clickable summary.
Selecting it opens Security, which is the single place for changing the policy,
reading its implications and confirming full project access.

The Android plugin is functionally unchanged and is included so the public APK
and Windows Connector share one release version.

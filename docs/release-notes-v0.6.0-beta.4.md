# RokidHub Codex v0.6.0-beta.4

This update fixes pairing in the packaged Windows Connector. Pairing codes are
now decoded correctly and appear in the GUI instead of replacement symbols.

It also adds per-project file and network access controls. A project row can be
selected for alias or permission editing without accidentally making it the
default project; only its radio control changes the default.

The Android plugin and its existing `v0.6.0-beta.3` APK are unchanged. This is
a Windows Connector-only hotfix release.
